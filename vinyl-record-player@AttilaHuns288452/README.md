# Vinyl Record Player Desklet

A vinyl record player desklet for the Cinnamon desktop environment.

## Features

- Spinning vinyl record on your desktop
- Audible turntable styling with a tonearm
- Right-click to interact

## Installation

Extract to ~/.local/share/cinnamon/desklets/
